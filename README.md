# Blance_Car 平衡车控制项目

基于 **STM32F103C8** 的两轮自平衡车控制固件。控制板实际使用 **MPU-6500** 六轴 IMU，当前软件沿用 `MPU6050` 模块命名，并使用 MPU-6050 兼容寄存器集访问。项目读取双路增量编码器反馈，通过串级 PID 完成速度、姿态和电机速度闭环控制；并提供串口遥控、电池电压检测与电量指示功能。

> 项目名称沿用原工程中的 `Blance_Car` 拼写。

## 功能概览

- MPU-6500 姿态采集：I²C 400 kHz 通信；软件以 MPU-6050 兼容模式的寄存器地址访问，使用陀螺仪与加速度计互补滤波计算欧拉角。
- 双电机闭环调速：通过左右编码器测速，分别以 1 ms 周期运行电机 PID。
- 平衡控制：5 ms 周期运行速度环、姿态环、角速度环及转向环四级串级 PID。
- 转向与行驶控制：通过 USART3 接收文本遥控指令，设置行驶速度与转向角速度。
- 电池管理：ADC 定时采样电池电压，三颗 LED 显示电量；低电压时全部闪烁。
- 安全使能：按键单击切换电机驱动使能，并重置控制器状态。
- 调试接口：USART2 预留高速串口（921600 bps）。

### 电源、执行机构与接口

- 电池输入为 `BAT+` / `BAT-`，原理图采用两节电芯电池盒。软件按满电约 **8.4 V** 的两串锂电池配置换算电压并设置告警阈值。
- `MT2492` 将电池电压降为 3.3 V，为主控、IMU 和逻辑部分供电；TB6612FNG 的电机电源直接来自 `BAT+`。
- 电池电压经 `R6 = 5.1 kΩ` 与 `R14 = 3.3 kΩ` 分压后进入 `PB0 / ADC1_IN8`（`VBAT_SENSE`）。
- 主电机驱动为 **TB6612FNG**，左右电机均使用正反转方向信号和独立 PWM；左右编码器均接入 A/B 相及电源。
- 左右执行电机均为 **GA25-170** 带编码器直流减速电机。公开的 GA25-370 / JGA25-370 170 rpm 规格表将此转速选项对应为 **35:1 减速比**；不同供电电压与厂商版本的空载和额定转速会不同，不能只凭“170”标称推断额定电流或力矩。[参考规格](https://precisionminidrives.com/product/25mm-gear-motor-with-encoder-48mm-type-model-nfp-jga25-370-en)
- 编码器磁环为 **11 对极**，即电机轴每转产生 11 个 A/B 相周期。当前程序只对 A 相双边沿计数，所以电机轴每转得到 `11 × 2 = 22` 个计数；按 35:1 减速比，车轮轴每转应为 **770 个计数**。
- 控制板预留五颗串接的可寻址 RGB 灯珠接口，数据线为 PA0 / TIM2_CH1。当前工程未在主循环中启用灯效模块。
- USART3 接至带射频天线的串口无线模块（原理图未标明模块型号），其串口配置为 9600 bps；因此遥控端必须使用相同串口参数。

### 设计核对说明

引脚分配同时与随附的 STM32F103C8T6 引脚资料核对过：PA8 对应 TIM1_CH1、PB6 对应 TIM4_CH1、PB0 对应 ADC1_IN8、PB10/PB11 对应 USART3，以及 PB8/PB9 对应重映射后的 I²C1。右编码器使用 PB3/PB4，因此程序会关闭 JTAG 以释放 PB3/PB4，但 SWD 调试接口仍可用。

### 编码器换算校正（重要）

当前 `user/app_encoder.c` 使用的减速比为 `30613 / 1500 ≈ 20.409:1`，因此位置与速度计算的分母为约 **449 计数/车轮转**。这与已确认的 GA25-170 35:1 减速比不一致。

若编码器确实安装在电机轴且 A 相双边沿均正常计数，则应将位置和速度换算中的减速比改为 `35.0f`，即使用 **770 计数/车轮转**。否则，当前计算的角度和角速度将约为实际值的 **1.72 倍**，并会影响电机速度环与平衡外环的整定。建议在车轮上做一圈标记，手动转动一整圈并读取 `encoder_l` / `encoder_r` 的增量，以实测计数优先确认。

轮胎半径按当前参数 `0.032 m` 计算，周长约为 `0.201 m`。170 rpm 的车轮空载理论线速度约为 **0.57 m/s**；这低于程序中 `0.7 m/s` 的遥控速度上限，实际可达速度还会受电池电压、载荷和打滑影响。因此，建议将遥控上限按实测结果下调或重新标定。

## 控制逻辑

控制器按下列链路工作：

```text
遥控移动速度 ─→ 速度环 ─→ 目标倾角 ─→ 姿态环 ─→ 目标俯仰角速度
                                                   │
编码器速度 ────────────────────────────────────────┘
                                                   ↓
                                        俯仰角速度环 → 目标线加速度
                                                   ↓
                                      倒立摆逆解 → 左右轮目标角速度
                                                   ↓
                           编码器反馈 ← 电机速度 PID ← TB6612 PWM 输出

遥控转向速度 ─→ 转向 PID（陀螺仪 Z 轴角速度反馈）─→ 左右轮差速
```

当前控制参数及车体模型参数定义在 `user/app_control.c`：

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| 控制周期 | 5 ms | 平衡控制与姿态更新周期 |
| 电机速度环周期 | 1 ms | 左右电机 PID 执行周期 |
| 轮胎半径 `rw` | 0.032 m | 用于速度、加速度换算 |
| 质心到轮轴距离 `lp` | 0.062 m | 倒立摆模型参数 |
| 最大遥控行驶速度 | 0.7 m/s | 指令映射上限 |
| 最大遥控转向速度 | 15 rad/s | 指令映射上限 |

不同车架、电机、电池或重心位置均需要重新标定以上参数及 PID 增益。

## IMU 寄存器与姿态配置

控制板的 U11 为 MPU-6500。MPU-6500 文档明确提供 MPU-6050 兼容模式寄存器表，因此当前 `app_mpu6050.c` 的命名和访问方式可用于该硬件，但建议在后续版本中改为 `app_mpu6500` 或 `app_imu`，以避免器件型号混淆。

当前工程的初始化配置如下：

| 寄存器 | 写入值 | 含义 |
| --- | ---: | --- |
| `PWR_MGMT_1` (`0x6B`) | `0x80`，随后 `0x00` | 复位后唤醒设备 |
| `GYRO_CONFIG` (`0x1B`) | `0x18` | 陀螺仪量程 ±2000 °/s |
| `ACCEL_CONFIG` (`0x1C`) | `0x00` | 加速度计量程 ±2 g |
| 数据区 (`0x3B` - `0x48`) | 读取 | 加速度、温度及三轴陀螺仪原始数据 |

姿态更新周期为 5 ms。当前版本没有读取 `WHO_AM_I`、没有显式配置数字低通滤波器，也没有保存陀螺仪零偏；这些是移植至新硬件或优化稳定性时应优先补充的项目。

## 遥控协议

遥控器通过 USART3 发送以换行符结尾的 ASCII 文本：

```text
move <turnspeed> <movespeed>\n
```

- `turnspeed`：整数百分比量级，程序按 `-turnspeed × 0.01 × 15` 转为目标转向角速度（rad/s）。
- `movespeed`：整数百分比量级，程序按 `-movespeed × 0.01 × 0.7` 转为目标行驶速度（m/s）。

例如：

```text
move 0 50
```

将设置约 `-0.35 m/s` 的行驶速度与 `0 rad/s` 的转向速度。正负方向受电机、编码器和机械安装方向影响；若与实际相反，请调整发送值符号或相应软件映射。

## 构建与下载

1. 安装 Keil MDK（工程使用 ARMCC/ARM-ADS 工具链）。
2. 在 Keil 中打开 `Blance_Car.uvprojx`。
3. 确认已安装 `Keil.STM32F1xx_DFP` 设备包（工程记录版本为 2.4.0）。
4. 选择 `STM32F103C8` 目标，执行 Build 编译。
5. 使用 SWD 下载器连接目标板，下载生成的固件。

工程已包含 STM32F10x 标准外设库源码，因此无需额外复制标准库。建议在通电前让车体保持静止；首次调试时将车轮悬空并先确认电机方向、编码器方向和姿态正方向。

## 运行说明

1. 检查电机、编码器、MPU-6500、电池检测及遥控串口连线。
2. 上电后等待 IMU 完成初始化，并保持车体静止。
3. 单击 PA11 对应按键以使能/禁用电机驱动；每次切换都会清空控制器历史状态。
4. 通过遥控串口发送 `move` 命令进行行驶和转向。
5. 观察三颗电量 LED：代码中以 7.5 V、7.4 V、7.0 V、6.5 V 作为分段阈值；低于 6.5 V 时三灯快速闪烁。

## 调参建议

- 先关闭电机使能，单独验证 MPU-6500 的 Pitch 正方向与编码器正方向。
- 在车轮悬空条件下确认 PWM、电机正反转和编码器计数是否对应。
- 优先从电机速度 PID 开始，再调姿态角速度环、姿态环和速度环。
- 每次只调整一组参数，并限制占空比和车体摆角，避免失控。
- 推荐先增加 `WHO_AM_I` 检测与静止零偏校准，再进行 PID 微调；陀螺仪零偏会直接影响静止平衡表现。

## 已知注意事项

- 遥控接收缓冲区长度为 64 字节；发送端应保证单行指令不超过此长度。
- 电池电压换算与 LED 阈值按两节锂电池电压范围设计。若电池或分压电路不同，应修改 `user/app_bat.c` 中的换算与阈值。
- 当前电量指示只使用 PA4、PA5、PA6 对应的三颗单色 LED。原理图中的五颗 RGB 灯珠并未由当前主工程驱动。
- 本项目直接驱动实际电机。调试时请固定车体或使车轮离地，并随时准备断电。
